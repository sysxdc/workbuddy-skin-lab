# WorkBuddy Skin Lab

让每天打开的 WorkBuddy，多一点只属于你的氛围。

我做这个小工具，不是为了替换 WorkBuddy 的界面，而是想把「换一张喜欢的背景、加一点恰到好处的环境粒子」变成一件简单、可恢复、能长期使用的事。当前稳定版本为 **v1.5.3**。

> 社区工具，与 WorkBuddy、腾讯均无隶属关系。它只通过本机回环调试连接临时叠加背景和粒子，不修改 WorkBuddy 安装文件。

## 你能得到什么

- 换上自己的背景，并保护侧边栏、输入框和回答区的可读性；
- 使用下雨、雷雨、雪花、爱心、星星或手输符号等环境粒子；
- 通过 AI 生成三张透明 PNG 粒子候选，例如樱花、萤火虫、纸飞机；
- 为 AI 粒子选择飘落、上浮、漂浮或横向掠过的受控轨迹，再在面板里安全微调；
- 把喜欢的背景、AI 粒子和运动设置保存到本机主题，重启后仍可继续使用；
- 随时恢复原生界面，不会删除你的主题文件。

我刻意没有再做会挂在 WorkBuddy 私有页面结构上的标题、卡片、宠物或文字模块。这样在 WorkBuddy 更新后，保留下来的功能更稳定，也不会突然丢掉你已保存的视觉素材。

## 三步开始

1. 从 [v1.5.3 Release](https://github.com/sysxdc/workbuddy-skin-lab/releases/tag/v1.5.3) 下载 `WorkBuddy-Skin-Lab-1.5.3-Windows.zip`。
2. 完整解压后，双击 `环境检查.bat`；检查通过后先保存 WorkBuddy 正在编辑的内容。
3. 双击 `开始使用.bat`。窗口重新打开后，点击右上角 `🎨` 开始调整。

运行条件：Windows 10/11、WorkBuddy 桌面端、Node.js 22 或更高版本。已在 WorkBuddy 5.3.8 验证。

完整步骤见：[小白安装教程（Markdown）](docs/BEGINNER_INSTALL.md) · [图文版安装教程（HTML）](docs/BEGINNER_INSTALL.html) · [公众号图文稿（HTML）](docs/WECHAT_ARTICLE_v1.4.1.html)

## 在 `🎨` 面板里可以做什么

- 选择主题或上传自己的背景；
- 设置浅色/深色、背景安全区、任务页背景和回答阅读层；
- 打开 `环境粒子特效`，选择内置天气、手输符号或 AI 透明 PNG 素材；
- 调整粒子的强度、速度、颜色、轨迹、摆动、旋转、缩放起伏和闪烁；
- 保存当前主题，让下一次启动自动恢复；
- 重置当前主题，或恢复 WorkBuddy 原生界面。

所有粒子都在背景层，始终 `pointer-events: none`：它们不能点击、也不会挡住输入框、按钮或弹窗。系统启用“减少动态效果”时，粒子会自动停止。

## AI 透明 PNG 粒子：生成一次，长期可用

AI 粒子与“手输符号（文字）”是两条独立功能：

- 手输符号只接收最多两个 Unicode 字符，例如 `🌸`、`♫`、`✨`；
- AI 粒子是透明 PNG 素材，必须在面板中选择 **AI 透明 PNG 素材** 才会显示；
- 生成完成后会建立一个新的本机派生主题，背景、三张候选粒子、默认选择和轨迹配方都会一起保存；
- 点击 `保存当前主题（下次启动）` 后，重启 WorkBuddy 会继续恢复这个派生主题，而不是回退到原主题的手输符号。

需要 AI 生成时，从同一 Release 安装：

1. `WorkBuddy-Skin-Lab-1.5.3-Skill.zip`；
2. `NoneLinear-Image-0.1.0-Skill.zip`，并完成图片服务配置；
3. 在 WorkBuddy 新任务中同时启用两个 Skill，描述粒子和轨迹；
4. 确认 3 次透明 PNG 生成调用，选择候选图并保存当前主题。

可直接试试这段提示词：

```text
@nonelinear-image @workbuddy-skin-lab
为我当前的 WorkBuddy 主题生成 AI 透明 PNG 粒子：淡粉色樱花花瓣，主体居中，透明背景，无文字、无 Logo、无水印；轨迹是随风缓慢飘落，轻微左右摆动，偶尔旋转，不闪烁。生成 3 张候选，选中后保存为可在下次启动继续使用的主题。
```

详细说明见：[AI 背景与粒子主题教程](docs/BEGINNER_WORKBUDDY_THEME.md)。普通换背景不需要 API Key、Python 或 AI 图片服务。

## 背景素材小建议

- 推荐 2560×1440、16:9、sRGB；最低 1920×1080；
- 优先 WebP/JPEG，建议小于 5 MB，硬限制 20 MB；
- 把重要主体放在画面右侧，给左侧和中央的操作区留出低细节空间；
- 四周留约 10% 安全边距，避免不同窗口比例裁切到主体；
- 不把文字、强高光或密集纹理放在回答区后方。

## 数据、隐私与恢复

主题与 AI 粒子默认保存在当前电脑：

```text
%LOCALAPPDATA%\WorkBuddySkinLab\themes
```

- 不会把 API Key、原始图片链接或大段 Base64 写入主题；
- 不要把私人主题、截图、`.env` 或 API Key 提交到 GitHub；
- AI 图片生成前，请自行确认图片服务商的隐私规则与素材版权；
- 双击 `恢复原生.bat`，或在面板中选择“恢复原生界面”，即可移除当前显示效果；主题文件仍会保留。

## 发布包内容

Windows 包包含环境检查、一键启动、一键恢复和内置主题；不包含 WorkBuddy 本体、个人主题、API Key 或本机运行数据。

如果你愿意分享自己做出的氛围主题，也欢迎关注公众号 **大模型评测及优化Nonelinear**，私信 **皮肤** 获取工具包与后续使用说明。
