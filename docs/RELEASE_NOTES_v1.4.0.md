# WorkBuddy Skin Lab v1.4.0

适配 WorkBuddy 5.3.8 的背景与粒子特效版本。

## 新增

- 增加下雨、雷雨、下雪、冒爱心、下星星和自定义符号粒子。
- 粒子支持轻、中、强三档强度，以及速度和颜色调整。
- 自定义符号最多支持两个 Unicode 字符，例如 `🌸`、`♫` 或 `✨`。

## 调整

- 雪花改用 `❄`、`❅`、`❆` 字形，并增加漂移、旋转和随机大小。
- 粒子保持在背景层，不接收点击，不遮挡 WorkBuddy 原生按钮、输入框或弹窗。
- 设置面板会根据窗口位置限制最大高度，避免超出屏幕。
- 完整移除不稳定的顶部图案和顶部文字功能；旧的本机顶部设置会被忽略。
- 更新 README、小白安装教程、HTML 图文教程和 AI 背景主题教程。

## 安装

普通用户下载 `WorkBuddy-Skin-Lab-1.4.0-Windows.zip`，完整解压后依次运行 `环境检查.bat` 和 `开始使用.bat`。

需要 AI 生成背景时，再安装 `WorkBuddy-Skin-Lab-1.4.0-Skill.zip` 和 `NoneLinear-Image-0.1.0-Skill.zip`。

本项目不会修改 WorkBuddy 安装文件。旧主题背景可以继续使用，但旧宠物、文字替换和装饰组件不会恢复。
