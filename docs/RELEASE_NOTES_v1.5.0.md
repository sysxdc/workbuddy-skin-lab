# WorkBuddy Skin Lab v1.5.0

新增 AI 自定义粒子素材与安全轨迹。

## 新功能

- 通过 WorkBuddy Skin Lab 与 NoneLinear Image Skill 生成三张 512×512 透明 PNG 粒子候选。
- 每次粒子生成单独确认三次调用；不自动重试，不保存 API Key、原始 URL 或大 Base64。
- 接受候选时创建用户派生主题，不会改写内置主题或来源主题。
- AI 的自然语言轨迹描述只转换为受限运动配方：飘落、上浮、漂浮或横向掠过。
- `🎨 → 环境粒子特效` 支持选择 AI 素材，并微调轨迹、摆动、旋转、缩放起伏和闪烁。

## 安全与兼容

- 自定义素材仅支持主题目录中的透明 PNG；最多三张、单张最大 1 MB、总计最大 3 MB。
- 粒子固定处于背景层，`pointer-events: none` 且 `aria-hidden`；不会替换或操作 WorkBuddy 原生组件。
- 旧主题自动保持兼容，继续使用原有天气、Emoji 或 Unicode 粒子。

## 验证

- Schema、作业授权、候选标准化、运行时素材选择和运动配方均有自动测试。
- 暂停和重新应用会清理粒子节点与运行时状态。
