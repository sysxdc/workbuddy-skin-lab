# WorkBuddy AI 主题：小白教程

这套工具让你直接在 WorkBuddy 对话中描述主题、查看图片、确认并保存。它不修改 WorkBuddy 安装文件，只通过本机 `127.0.0.1` 的调试连接临时显示主题；随时可以恢复原生。

## 开始前知道三件事

1. 普通生成流程需要6次图片调用：背景1次，确认后再生成5张装饰素材。选择“直接使用参考图”时，背景不调用生图，只剩5次。
2. 一次生图可能等待1–10分钟。开始后 WorkBuddy 会在当前窗口持续等待，不需要反复发送“继续”或“好了吗”，也不要重复提交。
3. 本地参考图会在你明确确认后上传到 NoneLinear 并取得公开 HTTPS 地址。请确认图片版权和隐私；工具不承诺远端自动删除。

## 第一步：安装和启动

准备两个 Skill ZIP：

```text
WorkBuddy-Skin-Lab-1.2.1-Skill.zip
NoneLinear-Image-0.1.0-Skill.zip
```

在 WorkBuddy 打开：

```text
更多 → 专家·技能·连接器 → 技能 → 添加技能 → 上传技能
```

分别导入并启用两个 Skill。

首次使用还需要：

- 安装 Node.js 22 或更高版本。
- 安装 Python 和 Pillow。
- 在启动 WorkBuddy 的同一个 PowerShell 窗口配置 `NONELINEAR_API_KEY`。
- 完全退出 WorkBuddy，然后在发布包中双击 `开始使用.bat`。

API Key 的完整设置方法见 [`NONELINEAR_SETUP.md`](../references/NONELINEAR_SETUP.md)。不要把真实 Key 发到聊天、截图或 GitHub。

## 第二步：选择背景方式

在 WorkBuddy 中发出主题需求，不需要打开 Codex。

在 WorkBuddy 新建任务并启用 `workbuddy-skin-lab` 与 `nonelinear-image`，然后使用下面任一种说法。

### A. 只用提示词生成

```text
请制作一个 WorkBuddy 主题，名字叫“雨夜书房”。
背景方式：只根据提示词生成。
风格：深蓝雨夜、木质书桌、暖色台灯，主体靠右，左侧留出文字空间。
```

### B. 根据参考图生成新背景

```text
请参考这张图片制作“春日庭院”主题。
背景方式：根据参考图生成新背景。
参考图：D:\Pictures\garden.png
保持配色和氛围，但重新生成适合宽屏 WorkBuddy 的画面。
```

本地图片上传前，WorkBuddy 会显示：

> 该图片将上传到 NoneLinear 服务器并获得公开 HTTPS URL。

同意时回复：

```text
确认本作业上传这一张参考图。
```

### C. 直接使用参考图

```text
请制作“我的插画”主题。
背景方式：直接使用参考图。
参考图：D:\Pictures\my-art.webp
```

工具会复制图片并居中裁切为 2048×1152，不修改原文件，也不产生背景生图调用。后续5张装饰素材仍会参考该图片生成。

公开 HTTPS 图片可以直接填写网址；HTTP、localhost、内网地址和带用户名密码的网址会被拒绝。

## 第三步：等待并查看背景

调用前 WorkBuddy 会提醒预计等待1–10分钟。完成后必须给你：

- 对话中可见的背景预览，或可点击的 HTTPS 地址；
- 标准化背景的本地保存路径；
- 当前采用的是生成、参考图生成还是直接使用。

没有看到图片或地址时，不要回复“确认”，直接说：

```text
请重新展示当前背景预览和地址，不要重新生图。
```

满意时回复：

```text
我确认使用这张背景，并授权继续执行5次派生素材调用。
```

不满意时说明要改什么。每次重新生图都需要新的明确授权；工具不会自动重试。

## 第四步：生成五张装饰素材

确认背景后会同时生成：

- 首页欢迎装饰1张；
- 日常办公、代码开发、设计创意图标各1张；
- 输入区装饰1张。

新主题的首页欢迎装饰默认没有徽标文字，只保留眉题、标题和说明。图片本身不包含文字、WorkBuddy 标志、UI框架或水印。

五张图共用你刚才的一次授权，但仍分别记账。Skill 会启动一个前台任务并行生成五张，每15秒保持一次活动状态，等全部返回后自动继续下载和校验；即使界面暂时显示“仍在运行”，它也会在同一轮继续等待，不会只留下“等待自动通知”。这段时间保持 WorkBuddy 窗口打开即可，不需要追问进度。

这一步可以一直留在当前任务页，不需要返回 Home。只有 WorkBuddy 本身被关闭或任务真的中断后，才发送：

```text
继续刚才的主题作业。
```

## 第五步：在当前任务页保存并应用

五张素材完成后回复：

```text
我确认保存并应用当前主题。
```

Skill 会在当前任务页完成：

1. 校验背景和五张素材；
2. 写入独立主题目录；
3. 保存为活动主题；
4. 直接应用任务页背景和配色。

不需要为了保存主题切换到 Home。以后正常打开 Home 时，工具才会自动检查真实锚点和尺寸；合格后显示五个模块，不合格时只保留背景，并在 🎨面板提示“Home组件待兼容”。

## 日常使用

- 拖动 🎨可以移动控制按钮，位置会自动记住。
- 点击 🎨可以预览已保存主题、修改首页文字、换背景或恢复原生。
- 选好主题后点击“保存当前主题（下次启动）”；看到“已保存”提示后，下次打开会自动恢复它，旧主题仍可继续切换。
- 点击“恢复原生界面”或运行 `pause` 后，所有注入节点、监听器和临时样式都会移除。

## 常见问题

### 等了很久没有结果

单次最多等待10分钟，五张派生素材会并行等待，通常不需要把五张的时间相加。正常情况下会持续显示前台保活并自动收尾；如果只出现“我将等待自动通知”然后对话结束，说明仍在使用旧 Skill，请导入最新 RC 并重新打开 WorkBuddy。只有 WorkBuddy 任务确实中断后才发送“继续”。如果显示 `outcome_unknown`，需要你再次明确授权后才能重试。

### 背景已经生成，但没有让我确认

发送：

```text
请运行 preview 展示当前背景，不要重新生成。
```

### 保存时还让我进入 Home

说明仍在使用1.2.0或更早版本。确认已导入并启用 `WorkBuddy-Skin-Lab-1.2.1-Skill.zip`，然后完全退出并重新打开 WorkBuddy。

### Home 没有显示装饰模块

打开 🎨查看兼容状态。窗口过小时先最大化；如果仍显示“待兼容”，保留背景使用并记录 WorkBuddy 版本和截图，反馈测试结果。不要自行填写 CSS 选择器。

### “+”菜单显示异常

先恢复原生再重新应用测试版。如果问题仍存在，保留菜单打开时的截图；不要调低菜单透明度，也不要修改 WorkBuddy 安装文件。
