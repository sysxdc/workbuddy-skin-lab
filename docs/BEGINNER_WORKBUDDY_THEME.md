# WorkBuddy AI 主题：五步小白教程

> **WorkBuddy 5.3.8 兼容说明：** 当前运行时采用“仅背景模式”。背景图片、主题切换、浅深色、背景安全区、任务页背景和回答阅读层仍可使用；旧主题中的首页自定义文字与装饰模块不会再注入。这样可避免 WorkBuddy 更新页面结构后出现文字丢失、图片错位或遮挡原生控件。

全流程都在 WorkBuddy 中完成，不需要 Codex。本工具不修改 WorkBuddy 安装文件，只通过本机 `127.0.0.1` 显示主题，随时可以恢复原生。

## 1. 安装

在 WorkBuddy 打开“更多 → 专家·技能·连接器 → 技能 → 添加技能 → 上传技能”，导入并启用：

```text
WorkBuddy-Skin-Lab-1.3.0-Skill.zip
NoneLinear-Image-0.1.0-Skill.zip
```

再解压 Windows 包，首次使用双击 `环境检查.bat`，通过后双击 `开始使用.bat`。需要 Node.js 22+、Python 和 Pillow。

## 2. 配置 API Key

在 PowerShell 输入下面两行，再从同一窗口启动 WorkBuddy：

```powershell
$env:NONELINEAR_API_KEY = "nl-xxx"
.\scripts\apply.ps1
```

不要把真实 Key 发到聊天、截图或 GitHub。更多配置方式见 [`NONELINEAR_SETUP.md`](../references/NONELINEAR_SETUP.md)。

## 3. 选择图片方式

在 WorkBuddy 新建任务，同时启用 `workbuddy-skin-lab` 和 `nonelinear-image`，直接说：

```text
请制作“雨夜书房”主题。使用提示词生成背景：深蓝雨夜、木质书桌、暖色台灯，主体靠右，左侧留出空间。
```

也可以说“根据这张参考图生成”，或“直接使用这张本地图片”。本地图片上传前会询问：

> 该图片将上传到 NoneLinear 服务器并获得公开 HTTPS URL。

确认后，工具会一次说明全部调用量：

- 提示词/参考图生成：3次单图背景调用（一个窗口内并行）+ 5次模块调用，共8次。
- 直接使用图片：不生成背景，只进行5次模块请求。

## 4. 一次确认并等待

确认完整调用量后保持当前 WorkBuddy 窗口打开。一次生图可能需要1–10分钟；五张模块会并行生成。你不需要发送“继续”或“好了吗”，也不要重复提交。

三张背景由一个 `run-backgrounds` 命令并行等待，返回后会展示图片或地址，自动先用方案1继续，不需要再次确认。五张模块全部使用 `quality=low`：欢迎装饰、三个 1024×1024 场景图标和输入区装饰。图片内不会生成文字、UI框架、WorkBuddy标志或水印。

如果任务真的中断，只发送：

```text
继续刚才的主题作业。
```

工具会恢复原作业，不会自动再次计费。

## 5. 保存和日常切换

生成完成后回复“确认保存并应用”。不需要返回 Home。点击可拖动的 `🎨`：

- “主题与背景”：切换/保存主题，点击方案1–3缩略图，或指定自己的图片。
- “文案设置”：点“切换下一套”，在专注、轻松、活力之间循环；每套可单独改文字。
- “显示效果”：调整明暗、背景安全区、任务页背景和回答阅读层。
- “模块装饰”：换单个模块图片或单项重置。
- “恢复与重置”：重置当前主题或恢复原生界面。

选好后一定点击“保存当前主题（下次启动）”。旧主题不会删除，下次仍可切换。

## 问题解决

### 等待后没有继续

确认安装的是 `1.3.0`。正常流程会在同一轮持续等待；只有任务确实中断才发送“继续刚才的主题作业”。出现 `outcome_unknown` 时必须重新授权，工具不会自动重试。

### 旧版提示“应返回3张，实际1张”

不要重新初始化，也不要删除作业。升级到 `1.3.0` 后发送“继续刚才的主题作业”；Skill 会恢复原 `jobId`。旧版那一次调用已经记账且没有保存图片地址，因此会先说明还缺3张，并等待你明确授权3次替代背景调用，然后用一个前台批次并行完成。新版如果只失败一部分，会保留成功候选，只请求补齐缺少数量。

### API Key 无效

完全退出 WorkBuddy，在配置 Key 的同一个 PowerShell 窗口重新运行 `apply.ps1`。只用状态命令检查，不要显示或粘贴 Key。

### “+”菜单异常

先在 `🎨 → 恢复与重置` 选择“恢复原生界面”，再重新应用主题。仍异常时保留菜单打开截图和 WorkBuddy 版本，不修改安装文件。

### 回答遮罩不见了

进入任务页，在 `🎨 → 显示效果 → 回答阅读层` 选择“显示”。遮罩只在真实 `[data-view-id="main-content"]` 存在时启用，不会猜测旧类名，也不会阻挡点击。

### Home 模块没出现

正常进入 Home 后查看 🎨 的兼容状态。窗口太小时先最大化；仍显示“待兼容”时保留背景使用，不要自行填写 CSS 选择器。

### 想永久删除 API Key

持久配置、删除方法和 cc-switch 兼容说明见 [`NONELINEAR_SETUP.md`](../references/NONELINEAR_SETUP.md) 后半部分。
