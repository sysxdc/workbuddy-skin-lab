# WorkBuddy Skin Lab v1.4.1

修复雪花、爱心、星星和自定义符号粒子排列成规则斜线的问题。

## 修复内容

- 将线性伪随机改为散列式确定性随机，打散横坐标、延迟、大小、透明度、漂移和旋转之间的相关性。
- 负延迟覆盖粒子的完整动画周期，启动时粒子均匀分布在不同高度。
- 雪花使用四段左右摆动的飘落轨迹。
- 爱心使用带缩放变化的摇摆上浮轨迹。
- 星星使用多段漂移、旋转和明暗闪烁的下落轨迹。
- 自定义符号使用独立的自由上浮轨迹，不再与爱心共用动画。
- 下雨和雷雨效果保持不变。

## 验证

- 在 WorkBuddy 5.3.8 中以高强度分别验证雪花、爱心、星星和自定义符号。
- 每类 50 个粒子均获得独立轨迹，横坐标与延迟的相关性接近 0。
- 自动化测试、语法检查、暂停与重新应用流程均通过。

普通用户下载 `WorkBuddy-Skin-Lab-1.4.1-Windows.zip`，完整解压后运行 `环境检查.bat` 和 `开始使用.bat`。
