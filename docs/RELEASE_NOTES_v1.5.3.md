# WorkBuddy Skin Lab v1.5.3

修复 AI 粒子派生主题重启后回退到原主题的问题。

## 修复内容

- `particle-v1` 的 `accept` 现在会自行写入一次性待启用主题，不再依赖 AI 对话额外执行应用命令。
- 待启用主题优先于旧的面板“下次启动”偏好；首次应用后会同步更新面板偏好并清除待启用标记。
- AI 粒子主题创建成功后，重启 WorkBuddy 仍会加载同一派生主题和三张 PNG 素材。
- 背景主题的 `accept` 也采用相同的持久化规则。

## 现有用户

已生成但未保存的主题，可在 `🎨 → 切换主题` 选择对应“·樱花”等派生主题后点击“保存当前主题（下次启动）”。
